# SignalJam

A non-intimidating wellness app that screens for changes in vocal, speech, and motor signals. The user runs a quick three-task session — sustained vowel, read-aloud passage, and a tap test paced by an audible metronome — and gets a combined **NeuroScore** they can track over time and share with a clinician.

Built with [Expo](https://expo.dev) (SDK 54) + expo-router. Originally scaffolded by [Fastshot](https://fastshot.ai); the screening flow, i18n layer, audio rhythm, and share/export features in this repo were built on top.

## What it does

- **One-tap screening that runs all three tasks in order**
  - Vocal Tone — sustain "Aaah" for 10 seconds
  - Speech Rhythm — read a randomly-picked 30-second passage in the user's language
  - Tap Test — tap along to an audible 100 BPM metronome click
  - At the end: a combined NeuroScore with per-metric breakdown, baseline drift, and a "What does this mean?" explainer
- **Full multi-language UI** — English, Spanish, French, Chinese (Simplified), Hindi, Arabic. Every screen, button, alert, and the reading passages are localised. Arabic renders RTL.
- **Persistent local history** — session list, sparkline trends, mini-trends per metric. No data leaves the device.
- **Native share sheet for exports** — Settings → Export Data and Results → Share with Clinician both produce a `signaljam-history-<timestamp>.txt` and pop the OS share menu (Mail, Messages, Drive, AirDrop, etc.).
- **Empty / first-run states** — no fake scores or demo sessions are shown before the user has actually completed a screening, and a "Delete All My Data" wipe sends them cleanly back to the language picker.

## Running locally

```bash
# install
bun install     # or: npm install

# start the Metro dev server
npx expo start
```
Please ensure that you are on the same Wi-Fi network as the device running the simulation.

Then either scan the QR with **Expo Go** (SDK 54-compatible build), or press `i` / `a` for a simulator.

### Building a static bundle for Expo Go

`expo export` defaults to Hermes bytecode (`.hbc`), which Expo Go can't load. The package scripts pass `--no-bytecode`:

```bash
npm run export            # all platforms, plain JS bundles into ./dist
npm run export:ios        # iOS only
npm run export:android    # Android only
```

The bundled `serve-expo.js` then serves `dist/` to Expo Go over LAN.

## Project layout

```
app/                       expo-router screens
  (onboarding)/index.tsx   language pick + 3-slide intro
  profile.tsx              age range, biological sex, nickname
  (tabs)/                  home · screening · history · learn · settings
  recording/[task].tsx     sequential vocal-tone → speech-rhythm → tap-test
  processing.tsx           animated "analyzing your signals"
  results.tsx              NeuroScore ring + metric cards + share
components/                NeuroScoreRing, Sparkline, TaskCard, LanguagePickerModal, ...
constants/
  Languages.ts             6-language metadata (code, native label, RTL flag)
  Translations.ts          flat string table for every UI key, all 6 languages
  SpeechParagraphs.ts      3–5 reading passages per language, picked at random
hooks/useT.ts              `useT()` → `t(key, vars?)` bound to settings.language
lib/shareHistory.ts        formats sessions as a .txt and invokes the OS share sheet
store/useAppStore.ts       zustand + AsyncStorage persistence (profile, sessions, settings)
assets/sounds/click.wav    metronome click generated by scripts/gen-click.js
```

## Privacy

Audio is processed locally and never leaves the device. Exports are user-initiated — nothing is uploaded automatically. SignalJam is a **screening tool, not a diagnostic device**; the disclaimer is shown in onboarding, Learn, and on every exported report.
